## 6. Leakage and architecture risks found

- Current-code universe differs from the active database universe.
- Historical universe membership is not sufficient to eliminate survivorship
  bias.
- Schema changes are not represented by a complete migration sequence.
- Existing labels overlap and are descriptive, not sealed OOS trades.
- Theme tags mix incompatible semantic categories and lack effective dates.
- Longbridge coverage is too sparse for cross-sectional/theme modeling.
- Company-action coverage is insufficient.
- Model artifacts, calibration, and predictive metrics do not exist yet.
- Backend and frontend application modules are overly concentrated.

schema-migration infrastructure; it may not rewrite historical data, introduce
predictive models, or activate Theme/Options production logic.
